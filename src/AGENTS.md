# Design Guidelines

For interface design, implementation, and review in this project, read and apply the project skill [apple-design](../skills/apple-design/SKILL.md). This is the user-selected design guide for future UI work, including typography, materials, interaction feedback, gestures, animations, and accessibility.

Use the repository copy as the project reference if another `apple-design` skill is installed globally. Apply it within the requested task; do not redesign unrelated components solely to adopt the skill.

The skill's introductory response applies only to a standalone invocation without a concrete task. For implementation or review requests, carry out the requested work.
